🔄 Fluxo de Processamento

  1. Cliente submete análise → API recebe (202 Accepted)
  2. Validação e autenticação → JWT verificado
  3. Enfileiramento → Tarefa adicionada à fila prioritária
  4. Worker processa → Análise de sentimento executada
  5. Resultado salvo → Banco de dados atualizado
  6. Cache atualizado → Respostas futuras instantâneas
  7. Webhooks disparados → Sistemas externos notificados
  8. Cliente consulta → Resultado retornado do cache

✨ Características Técnicas

  • 🔒 Segurança: JWT, bcrypt, rate limiting, CORS
  • ⚡ Performance: Cache distribuído, processamento assíncrono
  • 📈 Escalabilidade: Horizontal scaling, load balancing
  • 🛡️ Resiliência: Retry logic, dead letter queue, graceful shutdown
  • 📊 Observabilidade: Métricas, logs, health checks
  • 🔔 Notificações: Webhooks com retry exponencial

🎯 Tecnologias Utilizadas

  • Backend: Flask 3.0 (Python)
  • Autenticação: JWT + Bcrypt
  • Banco de Dados: SQLite (dev) / PostgreSQL (prod)
  • Cache: In-Memory (dev) / Redis (prod)
  • Filas: Priority Queue (dev) / RabbitMQ (prod)
  • Webhooks: HTTP POST com retry
  • Testes: Pytest
