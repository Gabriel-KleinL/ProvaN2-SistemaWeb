✅ USE: arquitetura_visual.html (visual mais bonito!)

📹 Durante a gravação:
   1. Abra o HTML no Chrome/Firefox
   2. Pressione F11 (tela cheia)
   3. Use Ctrl/Cmd + Plus para dar zoom
   4. Aponte com o cursor os componentes
   5. Destaque as integrações
   6. Mencione as estatísticas

💡 Roteiro sugerido:
   "Como vocês podem ver neste diagrama de arquitetura
    estilo AWS, nosso sistema possui 9 componentes principais
    distribuídos em 6 camadas:

    - Cliente interage via API Gateway
    - Middleware faz autenticação e rate limiting
    - Services processam a lógica de negócio
    - Workers fazem processamento assíncrono
    - Data Layer persiste tudo
    - External systems recebem webhooks

    No total, são mais de 18 endpoints e 12 integrações!"
